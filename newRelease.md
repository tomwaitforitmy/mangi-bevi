1. `npm run prerelease`
2. `git push --tags`
3. Warten bis Expo Workflow fertig ist
4. Apple Store:

- Version hinzufügen und benennen
- "What's New in This Version" ausfüllen
- Neuesten Build auswählen
- "Add for Review" klicken

5. Google Play Console:

- Testen und veröffentlichen --> Test --> Interner Test --> Release hochstufen --> Produktion
- Versionshinweise hinzufügen --> Weiter
- Veröffentlichungen – Übersicht --> Änderungen zum Review senden
